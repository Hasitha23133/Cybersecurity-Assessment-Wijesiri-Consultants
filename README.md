## 📌 Project Overview

This project was conducted as part of the **Information Security Risk Management (IE3052)** module at **Sri Lanka Institute of Information Technology (SLIIT)**.

The objective of this assessment was to evaluate the cybersecurity posture of an MSME (Micro, Small, and Medium Enterprise), identify key cyber risks, analyze existing security controls, and recommend practical and cost-effective cybersecurity improvements based on internationally recognized frameworks.

The selected organization for this assessment was **Wijesiri Consultants**, a small consultancy business operating primarily through cloud services and remote work practices.

---

## 🎯 Project Objectives

* Identify critical business assets.
* Analyze cybersecurity threats and vulnerabilities.
* Evaluate risk likelihood and impact.
* Assess existing security controls.
* Recommend affordable cybersecurity improvements.
* Conduct cybersecurity awareness training.
* Develop an implementation roadmap.
* Collect stakeholder feedback and evaluate outcomes.

---

## 🏢 Target Organization

**Wijesiri Consultants**

A small consultancy firm specializing in investment project consulting services and operating through a flexible remote-working model.

---

## 🔍 Scope of Assessment

The assessment focused on:

* Cloud-based storage and collaboration platforms
* Client project documentation
* Personal laptops and desktop computers
* Mobile devices used for business communication
* Email and online communication channels
* Remote work security practices

---

## ⚠️ Key Risks Identified

| Risk                                | Risk Level  |
| ----------------------------------- | ----------- |
| Unauthorized Cloud Access           | High        |
| Phishing & Social Engineering       | High        |
| Personal Device Data Exposure       | High        |
| Weak Remote Work Controls           | Medium-High |
| Limited Internal Security Resources | Medium      |

---

## ✅ Recommended Security Controls

* Multi-Factor Authentication (MFA)
* Cloud Access Management
* Device Security Policies
* Regular Backup Strategy
* Cybersecurity Awareness Training
* Incident Response Planning

---

## 🛠 Frameworks & Standards Used

* ISO/IEC 27005
* NIST SP 800-30 Rev.1
* Risk-Based Cybersecurity Assessment Methodology

---

## 📅 Implementation Roadmap

### Phase 1 – Immediate Actions

* Enable MFA
* Strengthen passwords
* Secure all work devices
* Identify critical assets

### Phase 2 – Short-Term Actions

* Review cloud sharing permissions
* Implement backup procedures
* Introduce secure device guidelines
* Assign cybersecurity responsibilities

### Phase 3 – Medium-Term Actions

* Conduct periodic awareness sessions
* Develop incident response procedures
* Review and improve implemented controls
